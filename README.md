## 🧩 Описание
ChekhovAgent — это Telegram-бот, который отвечает на текстовые запросы пользователей, опираясь на актуальные данные из Google Sheets.

Бот демонстрирует архитектурный подход к построению AI-агента:

- разделение слоёв приложения 
- использование внешних источников данных 
- интеграция с LLM 
- контейнеризация 
- автоматический деплой через CI/CD 

## ⚙️ Технологии

- Python >= 3.12
- aiogram 3 — Telegram Bot API (async)
- httpx — HTTP-клиент
- Google Sheets API (google-api-python-client)
- OpenAI / DeepSeek API — LLM (или mock-реализация)
- pydantic-settings — конфигурация через env
- pytest, pytest-asyncio — тестирование
- black, isort, flake8 — форматирование и линтинг
- Docker / docker-compose — контейнеризация


## 🧑‍💻 Функциональность

Реализовано:
- Приём текстовых сообщений от пользователя в Telegram
- Онлайн-чтение данных из Google Sheets при каждом запросе
- Поиск релевантной строки в таблице (по названию клуба)
- Формирование ответа с помощью LLM (или mock-LLM)
- Явное использование данных из таблицы в ответе
- Корректная обработка случая, когда данные не найдены
- Логирование:
входящих запросов,
обращений к Google Sheets,
обращений к LLM,
ошибок и исключений
- Юнит-тест бизнес-логики с моками внешних сервисов

## 🧪 Тестирование

В проекте реализованы юнит-тесты для проверки бизнес-логики бота с использованием моков внешних сервисов (Google Sheets, LLM).
Что проверяется:
- Генерация ответа ботом через LLMServiceMock (test_llm_service.py)
- Проверяется корректное формирование ответа при наличии данных
- Проверяется поведение при отсутствии данных в таблице
- Методы поиска данных в Google Sheets (мокированные)
- Бизнес-логика формирования ответа из внешних данных
- Асинхронное взаимодействие с внешними сервисами через мок-клиенты
 
команда для запуска тестов в терминале: pytest app/tests/

## 🛠 Установка и запуск

1. Клонируем репозиторий:

git clone https://github.com/EugenyBaz/ChekhovAgent.git
cd ChekhovAgent

2. Создаём .env (можно скопировать .env.example) с переменными:

TELEGRAM_BOT_TOKEN=<токен вашего бота><br>
GOOGLE_SERVICE_ACCOUNT_JSON=<путь к JSON сервисного аккаунта><br> 
GOOGLE_SHEETS_SPREADSHEET_ID=<ID таблицы><br>
DEEPSEEK_API_KEY=<ключ DeepSeek или LLM API><br>
DEEPSEEK_BASE_URL=https://api.deepseek.com <br>
USE_MOCK_LLM=True   # True — замоканный LLM, False — реальный DeepSeek<br>

- USE_MOCK_LLM=True — бот будет возвращать ответы необработанные LLM ([MOCK] …) для быстрого тестирования без внешних API.
- USE_MOCK_LLM=False — бот будет использовать реальный LLM (DeepSeek)

3. Запуск через Docker:

docker-compose up --build

4. Локальный запуск без Docker:

Замоканный режим:
- команда в терминале: poetry install
- команда в терминале: poetry run python main.py
